# 词间分享海报背景素材

分享海报现在使用静态 WebP 水墨背景（含右上角「词间」Logo 和朱红印章），正文由 SVG 排版、Canvas 导出。

## 安装素材

下载随本次变更提供的《词间分享背景-内置品牌版.zip》，将其中的 `public/share-bg/` 目录复制到仓库根目录，得到以下文件：

```text
public/share-bg/
  spring.webp     春山亭影
  mountain.webp   远山春晓
  lake.webp       江南烟水
  plum.webp       梅岸归舟
  moon.webp       月夜青山
```

本次 PR 提交了前端代码，**二进制图片素材需要另行复制到仓库**。在素材安装之前，分享预览会缺少背景，PNG 导出会提示“背景图片尚未安装”。

图片已统一处理为 1080 × 1920 WebP，单张约 125–160KB。无需外链或服务端图片生成；Vite 会把 `public/share-bg/` 下的文件作为静态资源发布。

## 界面行为

1. 词作和札记详情点击「分享图片」。
2. 在弹窗里选择背景缩略图、分享比例、正文节选和重点句。
3. 预览使用 SVG 在背景上叠加动态文本。
4. 下载时将背景作为 data URL 内联到 SVG，再绘制至 Canvas，导出 PNG。
5. Logo 与朱红印章属于背景素材，不再由 SVG 绘制。也不会显示底部分享口号。

## 验证

安装素材后执行 `npm run build` 并在浏览器中验证五种背景的 PNG 导出，特别检查中文字体、超长标题、段落截断以及 1:1 裁切。
